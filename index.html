Paid-ad rails

Paste a PeekPanda paid-ad rails response and this page lays out the feature shelves (launched this week, still live after 90 days) and per-advertiser shelves with standing stats and creatives. Nothing leaves your browser.

Optional: paste a report you saved earlier (CLI --format json or a --state file) to see what changed since then.

Where to get the JSON

The input comes from PeekPanda, an iOS competitor catalogue that keeps dated Meta and TikTok ad-library observations. Call:

curl --get 'https://api.peekpanda.com/v1/paid-ads/rails' \
  --header "Authorization: Bearer $PEEKPANDA_TOKEN" \
  --header 'x-genviral-tenancy: personal'

Over MCP this is the get_ads action rails. You need a PeekPanda account and an API key; the paid-ad rails reference lists every field. Related: paid ads library and search paid ads. The command-line version on GitHub makes the call for you, keeps a weekly diff and can post to Slack or Discord.

These figures describe the ads PeekPanda collected. They are not spend, reach or performance, and a longer run does not prove an ad works.
